## 🗂️ Repo Structure

```
.
├── script-name-1/
│   ├── script.py
│   └── README.md        # optional: longer notes specific to this script
├── script-name-2/
│   └── script.py
└── README.md             # this file
```

Each script/project gets its own folder once it grows beyond a single file. Simple one-off scripts can live loose at the root if that's cleaner.

---

## 🛠️ Requirements

- Python 3.x
- Dependencies listed per-script (see individual folders), or in a root `requirements.txt` if shared across projects

## 🚀 Usage

Generally:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>/<script-folder>
python script.py
```

Specific run instructions, if needed, will live in each script's own README.
